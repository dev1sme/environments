# Tài liệu

Nơi lưu và đọc tài liệu markdown nội bộ: spec, review, báo cáo, ghi chú kỹ thuật
theo từng dự án và task.

- Mỗi file `.md` là một trang. Menu bên trái tự sinh theo thư mục.
- Sửa file là trang tự cập nhật, không cần build hay deploy.
- Nút tải ở góc trang trả về file markdown gốc.
- Mở cho cả LAN, không có đăng nhập. Không để thông tin nhạy cảm ở đây.
