# Mô tả target cho `make help` và `make menu`. Sửa xong chạy `make help-check`.
#
# Target:   target | biến | mô tả
#   @Tên nhóm        -> tiêu đề nhóm
#   biến x=vd        -> bắt buộc, menu sẽ hỏi;  [x=vd] -> tuỳ chọn
#   mô tả bắt đầu ⚠  -> hiện màu vàng, dùng cho lệnh nguy hiểm
#
# Biến:     !var tên[@glob-target] | tiêu đề | nguồn
#   nguồn = lệnh shell  -> mỗi dòng 1 gợi ý (thêm "\t tag" nếu muốn), chạy ở
#                          thư mục repo, đã nạp sẵn .env
#           confirm     -> hỏi Có/Không, Có thì truyền tên=vd
#           skip        -> không hỏi (target tự hỏi, vd password)
#           để trống    -> nhập tay
#   @glob: chỉ áp cho target khớp glob. Dòng khớp đầu tiên thắng -> để cụ thể lên trước.
#   Biến không có !var -> nhập tay, tiêu đề là tên biến.
#
# Ẩn:       !hide target...   -> có trong makefile nhưng cố ý không hiện

!var n        | Service (n)    | docker compose config --services
!var p@cg-*   | Project (p)    | find "$PROJECTS_ROOT" -mindepth 1 -maxdepth 1 -type d -printf '%f\n' | sort
!var p        | Project (p)    | find projects -mindepth 1 -maxdepth 1 -type d -printf '%f\n' | sort
!var f        | File dump (f)  | ls -1t .data/dump/* | while read -r f; do printf '%s\t%s\n' "$f" "$(du -h "$f" | cut -f1)"; done
!var d        | Domain (d)     |
!var u        | User (u)       |
!var force    | Ghi đè cert đang có? (force=1) | confirm
!var pw       |                | skip

!hide help menu help-check build sh clean cg-sh cg-ui
